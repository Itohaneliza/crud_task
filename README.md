Create a Repo with 3 branches for each level.

Datastore: Mongo DB


Level 1: Basic CRUD Operations

Use Case: Library Management System

● Description: Build an API to manage books in a library. 
Each book should have the following fields:
1. title (string)
2. author (string)
3. isbn (string, unique)
4. publishedYear (number)
5. genre (string)

● Tasks:
1. Create an endpoint to add a new book.
2. Create an endpoint to list all books.
3. Create an endpoint to update a book's details using its isbn.
4. Create an endpoint to delete a book using its isbn.
